WooCommerce shipping integration with Carrybee courier service for Bangladesh.

== Description ==

Royal Carrybee integrates your WooCommerce store with Carrybee courier service, enabling seamless shipping management for businesses in Bangladesh.

= Features =

* **WooCommerce Shipping Method** - Adds Carrybee as a shipping option at checkout
* **Location Selection** - City, Zone, Area cascading dropdowns
* **Automatic Order Creation** - Creates Carrybee parcel when order is placed
* **Bulk Actions** - Create or Sync multiple Carrybee orders at once from WooCommerce
* **Real-time Tracking** - Order status updates via webhooks
* **Multi-Store Support** - Manage multiple pickup locations
* **Sandbox Mode** - Test before going live

= Requirements =

* WordPress 5.6+
* WooCommerce 5.0+
* PHP 7.4+
* Carrybee API credentials

== Installation ==

1. Upload `royal-carrybee` folder to `/wp-content/plugins/`
2. Activate through 'Plugins' menu
3. Go to WooCommerce → Carrybee
4. Enter your API credentials
5. Add Carrybee to a shipping zone

== Frequently Asked Questions ==

= How do I get API credentials? =

Contact Carrybee at info@carrybee.com or call 09613 555 111.

= Can I test before going live? =

Yes! Use sandbox mode with the provided test credentials.

= Does it support COD? =

Yes, COD (Cash on Delivery) is fully supported.
